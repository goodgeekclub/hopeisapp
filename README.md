## Overview
The social volunteer project that gives a hope to youth generation.
This project built by youth volunteers in short time around 2 months to launch.
This Webapp could serve a large of client in a minute.
Some of participation has been had growth habit and mindfulness after continuing to use this

## Tech Stack

### Frontend
- Typescript
- Angular17

### Backend
- Typescript
- NestJs
- Serverless Framework v.3
- MongoDB Atlas

### Infrascture
- AWS S3 Static Web Hosting
- AWS Cloudfront CDN
- AWS Lambda
- AWS API Gateway
- AWS CloudFormation
- MongoDB Serverless Atlas
- Firebase Authenticate

### Other
- Terraform (IAC)
- Github Actions (CI/CD)
- Docker Compose (Local Dev)
- Github Project
